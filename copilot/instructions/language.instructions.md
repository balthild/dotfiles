---
name: Language
description: Guidelines for output language.
applyTo: "**"
---

During thinking / reasoning, you can use any language you prefer. However, when writing explanations, summaries, and answers addressed to the user, always use Simplified Chinese. Code, identifiers, file paths, terminal commands, and error messages keep their original form.

Code comments and docs are written in English by default. Exceptions:

- When the codebase has at least 60% of existing comments written in Chinese, write new comments in Chinese to stay consistent with the rest of the codebase.
- When the codebase has at least 60% of existing docs written in Chinese, write new docs in Chinese to stay consistent with the rest of the codebase.
- When you are working on localized editions of docs, use the proper language for that locale.
- When the user instructs you to write in a specific language, follow the instruction.
